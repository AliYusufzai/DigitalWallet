Digital Wallet API — a backend system built with ASP.NET Core 10 following 
a clean N-Layer architecture (API, Application, Domain, Infrastructure). 

Features:
- JWT Authentication (register, login)
- Wallet management (create, view balance)
- Deposits and withdrawals
- Wallet-to-wallet transfers
- Transaction history with pagination

Tech Stack: ASP.NET Core 10, Entity Framework Core, SQL Server, BCrypt, JWT Bearer
